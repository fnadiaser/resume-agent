# ИИ-агент для резюме и сопроводительных писем

Командный проект интенсива «ИИ-инженер» (Школа 21 × РУДН, октябрь 2026). Telegram-бот: пользователь рассказывает о себе и присылает ссылку на вакансию hh.ru, а бот пишет резюме и сопроводительное письмо под неё на русском или английском.

## Как работает
```
Пользователь → Telegram-бот → LangGraph
   ├─ агент профиля   — извлекает опыт, навыки, образование из свободного текста; уточняет пробелы (до 2 раундов)
   ├─ агент вакансии  — загружает страницу hh.ru, выделяет требования и ключевые слова
   ├─ агент резюме    — пишет полное резюме под вакансию, не выдумывая опыт
   ├─ агент письма    — сопроводительное письмо
   └─ редактор        — правки по запросу, экспорт в DOCX/PDF
```

## Моя часть
Агенты профиля, вакансии и резюме:
- структурированный вывод через pydantic + `with_structured_output`;
- уточняющие вопросы при расплывчатых ответах с лимитом раундов;
- нормализация ссылок hh.ru и запасной сценарий, если модель не вернула структуру;
- переход на GigaChat-2-Max, чтобы модель не придумывала опыт.

## Команда
Надежда Федорова — профиль, вакансия, резюме · Настя — граф LangGraph и письма · Лиза — редактор и экспорт DOCX/PDF · Амелия — Telegram-бот, хранение, локализация ru/en
